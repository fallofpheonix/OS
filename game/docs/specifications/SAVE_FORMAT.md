---\nStatus: Draft\nImplementation: 0%\nConfidence: High\n---\n# Game Save Format Specification\n\n> This document defines the binary and JSON formats for game saves (state snapshots).\n\n## 1. Format Versions\n- `v1.0`: Initial protobuf-based binary format.\n\n## 2. Structure\n- `Header`: Version, Seed, Tick, PlayerID.\n- `Entities`: List of serialized entity states.\n- `Environment`: Weather, Time-of-day, Global Flags.\n- `ReplayIndex`: Pointer to the Ledger block corresponding to this save.\n\n--- \n*Refer to [WORLD_STATE.md](./WORLD_STATE.md) for the schema definitions.* \n
