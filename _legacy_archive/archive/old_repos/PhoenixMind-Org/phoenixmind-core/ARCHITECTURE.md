# PhoenixMind-Core Architecture

## 1. Safety Mandate
The core is read-only. Modification is forbidden.
All evolution occurs via Assisted Evolution:
1. Observation (Sandbox)
2. Proposal (Agent-led)
3. Validation (Test Agent)
4. Human Approval (The Gate)

## 2. Dependency Matrix
- Memory-DB (Read-Only)
- Validator (Enforcer)
- Sandbox (Isolation)
