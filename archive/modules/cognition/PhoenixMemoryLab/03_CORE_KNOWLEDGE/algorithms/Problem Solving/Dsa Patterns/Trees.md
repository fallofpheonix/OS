### Traversal

- **DFS (Pre / In / Post order)**: Recursively visit nodes in specific orders to process tree structure.
- **BFS (Level order / zigzag / right side view)**: Traverse level-by-level using a queue for layered views.

---

### Recursion Patterns

- **Top Down Approach**: Pass information from parent to children during recursion.
- **Bottom Up Approach**: Compute results from children and return values upward.

---

### Path Based

- **Max Path Sum**: Compute maximum sum across any path by combining left and right contributions.
- **Diameter / Height / Depth**: Measure longest path or node levels using recursive aggregation.

---

### BST (Binary Search Tree)

- **BST**: Use ordered property (left < root < right) to enable efficient search and updates.
