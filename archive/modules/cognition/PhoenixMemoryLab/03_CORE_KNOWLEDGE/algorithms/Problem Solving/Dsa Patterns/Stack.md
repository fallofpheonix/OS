### Monotonic Stack

- **Monotonic Stack (Increasing)**: Maintain elements in increasing order to find next smaller relationships.
- **Monotonic Stack (Decreasing)**: Maintain elements in decreasing order to find next greater relationships.

---

### Nearest Element

- **Next Greater**: Find the next element to the right that is greater using a decreasing stack.
- **Next Smaller**: Find the next element to the right that is smaller using an increasing stack.
- **Previous Variants**: Apply the same logic in reverse to find left-side nearest elements.

---

### Range / Span

- **Range / Span**: Use stack to compute how far elements extend before a constraint breaks.

---

### Min/Max Stack

- **Min/Max Stack**: Augment stack to retrieve current min or max in O(1).

---

### Expression Handling

- **Expression Handling**: Use stack to evaluate or convert expressions (infix, postfix, prefix).

---

### Histogram Pattern

- **Histogram Pattern**: Use stack to compute largest rectangle area by tracking boundaries of heights.
