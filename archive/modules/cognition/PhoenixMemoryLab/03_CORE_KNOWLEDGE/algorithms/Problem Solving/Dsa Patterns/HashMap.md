- **Frequency Based**: Count occurrences of elements to make decisions or comparisons.
- **Lookup Based**: Store values for O(1) existence or complement checks.
- **Set Based**: Use hash set for uniqueness and fast membership testing.
- **Index Mapping**: Map values to indices to track positions or resolve constraints.
- **Grouping Pattern**: Group elements by a computed key (e.g., sorted form, frequency signature).
