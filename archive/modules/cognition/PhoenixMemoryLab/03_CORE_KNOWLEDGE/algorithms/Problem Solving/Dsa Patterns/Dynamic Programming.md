### Core

- **1D DP**: Store state in a single array where each index depends on previous states.
- **2D DP**: Use a matrix to represent states with two varying parameters.

---

### Transition Type

- **Linear DP**: Each state depends on a fixed number of previous states.
- **Grid DP**: States transition based on movements in a grid (e.g., up/left).
- **Decision DP**: Choose optimal among multiple options at each state.

---

### Pattern Types

- **Knapsack**: Decide inclusion/exclusion of items under constraints.
- **Sequence DP**: Compare or build sequences (e.g., LCS, LIS).
- **Partition DP**: Split problem into segments and optimize over partitions.
- **Interval DP**: Solve over subarrays by expanding interval boundaries.

---

### Advanced

- **Bitmask DP**: Represent subsets/states using bitmasks for exponential state compression.
- **Digit DP**: Process numbers digit-by-digit under constraints.
- **DP on Trees**: Compute states over tree structure using DFS.

---

### Optimization

- **Memoization**: Top-down recursion with caching to avoid recomputation.
- **Tabulation**: Bottom-up iterative filling of DP table.
