### Interval Greedy

- **Activity Selection**: Select maximum non-overlapping intervals by earliest finish time.
- **Non-overlapping Intervals**: Choose intervals greedily to avoid conflicts.
- **Minimum Removals**: Remove minimum intervals to eliminate overlaps.

---

### Scheduling Greedy

- **Deadline Based Scheduling**: Schedule tasks to maximize count within deadlines.
- **Profit Based Selection**: Pick tasks with highest profit under time constraints.

---

### Resource Allocation

- **Minimum Platforms / Rooms**: Track overlaps to allocate minimum resources needed.
- **Meeting Rooms**: Use sorting/heap to assign rooms minimizing conflicts.

---

### Jump Game Pattern

- **Jump Game Pattern**: Greedily track farthest reachable index to determine feasibility.

---

### Huffman / Merge Cost

- **Huffman / Merge Cost**: Combine smallest elements first to minimize total merge cost.
