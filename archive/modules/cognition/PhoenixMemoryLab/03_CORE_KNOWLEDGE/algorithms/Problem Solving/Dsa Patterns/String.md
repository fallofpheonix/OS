### Sliding Window (String)

- **Longest substring without repeat**: Maintain a window with unique characters using a set/map.
- **Minimum window substring**: Expand to include all required chars, shrink to find smallest valid window.
- **Anagram / permutation in string**: Use frequency counts in a fixed window to detect matches.

---

### Two Pointers (String)

- **Palindrome check**: Compare characters from both ends moving inward.
- **Reverse words / characters**: Swap characters using two pointers in-place.
- **String compression**: Use read/write pointers to compress consecutive characters.

---

### Pattern Matching

- **KMP (failure function)**: Use prefix function to avoid redundant comparisons in pattern search.
- **Rabin-Karp (rolling hash)**: Compare substring hashes to find pattern matches efficiently.
- **Z-algorithm**: Precompute longest prefix matches at each position for linear-time searching.
