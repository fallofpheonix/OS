- **Bubble Sort**: Repeatedly swap adjacent elements to push largest elements to the end.
- **Selection Sort**: Repeatedly select the minimum element and place it at the correct position.
- **Insertion Sort**: Insert each element into its correct position in a growing sorted prefix.
- **Merge Sort**: Divide array, recursively sort halves, and merge them in O(n log n).
- **Quick Sort**: Partition around a pivot and recursively sort subarrays.
- **Heap Sort**: Use a heap to repeatedly extract the maximum/minimum element.
- **Counting Sort**: Count occurrences of values to sort in linear time for small ranges.
- **Radix Sort**: Sort numbers digit by digit using a stable intermediate sort.
- **Bucket Sort**: Distribute elements into buckets and sort each bucket individually.
