### Backtracking (Exploration)

- **Decision Tree**: Model all possible choices as a recursive tree of states.
- **Choose–Explore–Unchoose**: Pick an option, recurse, then revert state to try others.
- **Subsets (Power Set)**: Generate all subsets by including/excluding each element.
- **Permutations / Combinations (nCr)**: Enumerate all orderings or selections using recursion.
- **Word Search (Grid)**: DFS with backtracking to explore valid paths in a grid.
- **Palindrome Partitioning**: Split string into all partitions where each substring is palindrome.

---

### Pruning / State Tracking

- **Pruning / State Tracking**: Cut branches early using constraints and track visited/used states.

---

### Divide & Conquer

- **Merge Sort Pattern**: Recursively split array and merge sorted halves.
- **Quick Select (Kth Largest)**: Partition array to directly locate kth element in average O(n).
- **Count Inversions**: Use merge process to count out-of-order pairs efficiently.
