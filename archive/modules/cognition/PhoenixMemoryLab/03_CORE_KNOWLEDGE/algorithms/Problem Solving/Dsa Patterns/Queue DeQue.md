
- **FIFO Processing**: Process elements in arrival order using a queue.
- **Level-wise Processing**: Use queue to process elements layer-by-layer (e.g., BFS).
- **Circular Queue Pattern**: Treat queue as cyclic to reuse space or simulate rotation.
- **Deque Based**: Use double-ended queue for efficient insert/remove from both ends (e.g., sliding window).
