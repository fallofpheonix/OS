### Segment Tree

- **Range Query**: Answer range queries (sum/min/max) in O(log n) using a tree over intervals.
- **Lazy Propagation**: Defer updates to efficiently handle range updates without full traversal.

---

### Fenwick Tree (Binary Indexed Tree)

- **Prefix Query**: Maintain prefix sums with O(log n) updates and queries using bit manipulation.
