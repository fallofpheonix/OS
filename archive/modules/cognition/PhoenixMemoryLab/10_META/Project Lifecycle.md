# Project Lifecycle

```text
IDEA -> PLANNING -> ACTIVE -> BLOCKED -> MAINTENANCE -> COMPLETED -> ARCHIVED
                                           |
                                           v
                                         FAILED
```

## Start
- Create code folder in `~/engineering/workspace/active/`.
- Create project note in `05_PROJECTS/ACTIVE/`.
- Run independence checklist.
- Update `10_META/dashboards/Project_Dashboard.md`.

## Complete
- Move code folder to `~/engineering/workspace/archived/`.
- Move project note to `05_PROJECTS/COMPLETED/`.
- Extract at least two failure notes and one ADR.
- Update dashboards.

## Fail
- Move project note to `05_PROJECTS/FAILED/`.
- Document root failure.
- Extract reusable failure notes.
