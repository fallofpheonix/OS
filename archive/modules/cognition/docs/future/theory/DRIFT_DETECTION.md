Detection Triggers\n- **Observation Gap:** Difference between predicted state $S_{t}$ and actual state $S'_{t}$.\n- **Confidence Collapse:** Rapid drop in $C_{final}$ for a specific knowledge domain.\n\n## 2. Correction Loop\n1. **Isolate Domain:** Mark affected knowledge as "Uncertain".\n2. **Gather Evidence:** Increase sampling rate of related Ledger events.\n3. **Re-train/Calibrate:** Update model weights or logic to align with new data.\n\n--- \n*Refer to [docs/phoenixmind/SELF_EVOLUTION_MODEL.md](../SELF_EVOLUTION_MODEL.md) for correction actions.* \n
