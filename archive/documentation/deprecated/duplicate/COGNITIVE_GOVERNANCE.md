# Cognitive Governance

Purpose
-------
Defines constraints, approval policies, and constitutional enforcement for adaptive cognition.

Structure
---------
- Constitutional Enforcement: invariant enforcement and multi-signer changes
- Adaptive Boundaries: allowable adaptation scope
- Evolution Constraints: safe mutation policies
- Branch Governance: trusted branches and approvals
- Stability Preservation: emergency brakes and rollback policies
