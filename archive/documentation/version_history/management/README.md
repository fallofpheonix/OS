# Program Management

Owns execution control, roadmaps, milestones, risks, budgets, dependency graphs, and reports.

No product code belongs here.

Primary inputs:

- `project_stages/FINAL_REPORT.md`
- `project_stages/MASTER_STAGE_MAP.md`
- `project_stages/DEPENDENCY_GRAPH.md`
- `project_stages/EXECUTION_ORDER.md`
- `project_stages/RISK_REGISTER.md`

## Subdirectories

- `roadmap/`: release and stage plans.
- `milestones/`: stage exit milestones.
- `gantt/`: timeline views.
- `risks/`: risk registers and mitigations.
- `budgets/`: time, compute, storage, and cost budgets.
- `execution/`: active execution plans.
- `dependency_graphs/`: generated and hand-maintained dependency graphs.
- `reports/`: status and review reports.
