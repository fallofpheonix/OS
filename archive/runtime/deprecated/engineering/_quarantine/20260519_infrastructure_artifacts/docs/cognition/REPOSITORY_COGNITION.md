# Repository Cognition

Purpose
-------
Describes how cognition understands, reasons about, and edits repository artifacts.

Structure
---------
- AST Understanding: parsing, semantic models
- Symbol Awareness: indexes, cross-file references
- Dependency Reasoning: runtime and build deps
- Architecture Awareness: module boundaries and intent
- Semantic Diffing: meaning-aware change detection
- Context Injection: safe context splicing for edits
