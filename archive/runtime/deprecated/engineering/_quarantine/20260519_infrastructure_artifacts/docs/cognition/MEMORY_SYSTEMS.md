# Memory Systems

Purpose
-------
Defines persistence, consolidation, retrieval and decay semantics for cognition.

Structure
---------
- Episodic Memory: raw event traces, sessions
- Semantic Memory: distilled facts and models
- Procedural Memory: learned procedures and heuristics
- Failure Memory: categorized failures and repair outcomes
- Replay Memory: snapshots for deterministic replay
- Consolidation: schedules and triggers
- Compression: summarization and lineage preservation
- Retrieval: policies, indices, recall context
- Memory Decay: expiration and archival rules
