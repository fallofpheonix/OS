# Temporal Reasoning

Purpose
-------
Defines sequence modeling, long-horizon planning, and temporal compression used by cognition.

Structure
---------
- Temporal State: time-indexed state representations
- Sequence Modeling: trajectories and encodings
- Future Prediction: rollout and scoring
- Delayed Consequences: modeling lagged effects
- Long-Horizon Planning: temporal decomposition and cost models
- Event Segmentation: episodes and boundaries
- Temporal Compression: summarization and abstraction
