# Local Runtime

Purpose
-------
Defines how cognition runs on a local developer machine, including storage ownership and resource policies.

Structure
---------
- Local Architecture: components and directories
- Resource Constraints: limits and quotas
- Local Scheduling: single heavyweight inference rule
- Local Model Policies: fallback and routing
- Filesystem Layout: paths for state and snapshots
- Runtime Limits: timeouts and watchdogs
