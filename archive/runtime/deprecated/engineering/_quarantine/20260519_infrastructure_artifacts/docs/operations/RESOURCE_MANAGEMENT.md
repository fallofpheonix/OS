# Resource Management

Purpose
-------
Defines compute governance: CPU/GPU/RAM policies, quotas and branch-level limits to prevent exhaustion.

Structure
---------
- CPU Policies: quotas and throttling
- GPU Policies: allocation and preemption
- RAM Constraints: per-session limits
- Branch Limits: parallel branch caps
- Context Limits: max token/context sizes and trimming
