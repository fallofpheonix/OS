# Release Process

Purpose
-------
Defines safe release gates, migration safety, and rollback strategies for cognitive changes.

Structure
---------
- Release Gates: automated and manual checks
- Validation Criteria: replay and invariant checks
- Rollback Procedures: fast rollback and forensic capture
- Migration Safety: data and schema migration rules
- Replay Verification: post-release validation
