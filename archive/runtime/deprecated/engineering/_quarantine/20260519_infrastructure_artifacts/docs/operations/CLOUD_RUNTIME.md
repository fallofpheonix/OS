# Cloud Runtime

Purpose
-------
Defines distributed execution, synchronization boundaries, and failure semantics for cloud deployments.

Structure
---------
- Cloud Providers: supported providers and roles
- Distributed Execution: task routing and state slicing
- Remote Models: API-based model usage and quotas
- Synchronization: eventual vs strong consistency boundaries
- State Boundaries: what remains local vs remote
- Failure Recovery: hybrid recovery modes
