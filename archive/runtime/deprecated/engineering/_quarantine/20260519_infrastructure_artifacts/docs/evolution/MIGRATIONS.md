# Migrations

Purpose
-------
Defines safe migration patterns for schemas, events, memories and runtime changes to preserve temporal continuity.

Structure
---------
- Schema Migrations: versioned transforms and compatibility
- Event Model Migrations: versioned events and replay compatibility
- Memory Migrations: backfills and consolidation
- Runtime Migrations: rolling upgrade patterns
- Branch Compatibility: cross-version branch handling
