# Ecosystem Governance Rules

## Rules

1. **No delete without archive**: No repository or module shall be deleted without being first moved to the archive/ directory and updated in the registry.
2. **Manifest first**: All changes to the ecosystem must be reflected in the relevant manifest or registry file before execution.
3. **Runtime validation required**: Any new repository or module must pass runtime compatibility validation before being marked as ACTIVE.
4. **Research mapping mandatory**: Every repository must be mapped to at least one research domain or lineage.
5. **Ownership required**: Every repository must have a defined owner in the registry.
6. **Boundary checks enforced**: Cross-domain dependencies must be explicitly declared and checked for coupling violations.
