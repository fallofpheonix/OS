# Neuromorphic Research (P6)

Event-driven and biologically inspired computing research for the Astraeus Scientific Stack.

## Purpose
Exploration of neuromorphic architectures, spiking neural networks (SNNs), and brain-inspired learning rules.

## Domains
- **Spiking Systems**: Modeling of spiking neurons and synchronous/asynchronous circuits.
- **Plasticity**: Hebbian learning, STDP (Spike-Timing-Dependent Plasticity), and homeostatic mechanisms.
- **Attention**: Dynamic resource allocation and saliency modeling.
- **Energy Models**: Analysis of compute efficiency and low-power event-driven systems.
- **Temporal Dynamics**: Time-varying signals and delay-line processing.
- **Event Processing**: Asynchronous stream processing and filtering.

## Structure
- `spiking/`: SNN models and neuron dynamics.
- `plasticity/`: Learning rules and synapse modeling.
- `attention/`: Attention mechanisms and routing.
- `energy_models/`: Power analysis and efficiency benchmarks.
- `temporal_dynamics/`: Time-series and delay processing.
- `event_processing/`: Asynchronous event handlers.
- `runtime/`: Core execution logic and manifests.
- `docs/`: Technical documentation.
- `research/`: Neuromorphic research and theory.
- `tests/`: Comprehensive test suite.
- `examples/`: Usage demonstrations.
- `configs/`: System configurations.

## Registry
Integrated with the Astraeus Scientific Stack via `layer_registry.yaml`.
