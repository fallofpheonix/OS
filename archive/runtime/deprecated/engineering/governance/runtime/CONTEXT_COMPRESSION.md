# Context Compression

Defines when and how working memory and episodic traces are compressed into semantic artifacts.

Topics
------
- Compression triggers (age, memory pressure, consolidation schedule)
- Episodic summarization rules
- Semantic consolidation pipeline and artifact schemas
- Preservation of causal lineage during compression

Principle
---------
Compression must not remove causal lineage necessary for replay and attribution.
