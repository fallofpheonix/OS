# Terminology

Canonical glossary for Astraeus governance and documentation.

Terms
-----
- Cognition: the system's capacity to form beliefs, plan, and update state.
- World state: structured representation of repository and environment.
- Branch: an experimental or feature line in version control.
- Replay: deterministic re-execution of event history to reproduce state.
- Invariant: a rule that must not be violated by system changes.
- Repair: a set of actions to restore a violated invariant or fix failures.
- Memory trace: recorded execution event in episodic memory.
- Schema: structured contract for stored artifacts.
