# Long-Term Direction

Phased trajectory and high-level expectations for the next 3–10 years.

Phase overview
--------------
- Phase 0: Architectural definition (governance and invariants).
- Phase 1: Environment hardening and reproducibility.
- Phase 2: Repository cognition and symbol graphs.
- Phase 3: Hierarchical memory and consolidation.
- Phase 4: Belief, uncertainty, and temporal planning.
- Phase 5: Causal repair and intervention planning.
- Phase 6: Adaptive orchestration and distributed cognition.

Strategic principles
--------------------
- Stability first, cognition second, adaptation third.
- Enforce invariants before allowing policy changes.
- Preserve temporal continuity across migrations.

Risks and mitigations
---------------------
- Risk: environment rot — Mitigation: reproducible bootstrap and CI gates.
- Risk: hallucination-driven mutations — Mitigation: repository grounding and invariant checks.
