## Purpose
Remote-first workflow to manage local storage.

## Workflow
1. **Clone**: Pull necessary repositories from GitHub.
2. **Edit**: Perform required modifications locally.
3. **Push**: Commit and push changes back to remote.
4. **Remove Local**: Delete the local copy after verification.
5. **Restore**: Re-clone when needed for future work.
