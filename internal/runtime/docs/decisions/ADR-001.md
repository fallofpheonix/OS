---\nStatus: Implemented\nImplementation: 100%\nConfidence: Proven\n---\n# ADR-001: BFT Consensus Selection

## Context
Phoenix OS needs a consensus mechanism that handles Byzantine (adversarial) node failures in untrusted environments.

## Decision
We implement a lightweight variant of PBFT (Practical Byzantine Fault Tolerance) with a static set of validators, avoiding proof-of-work overheads.

## Consequences
- **Pros**: Sub-second finality; low CPU/energy overheads.
- **Cons**: Scale limits (recommended maximum of 64 nodes due to message complexity).
