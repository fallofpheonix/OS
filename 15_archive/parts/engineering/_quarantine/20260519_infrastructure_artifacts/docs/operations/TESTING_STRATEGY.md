# Testing Strategy

Purpose
-------
Defines verification practices focused on cognition behaviors, replayability, and long-session stability.

Structure
---------
- Unit Tests: core logic and contracts
- Integration Tests: runtime interactions
- Replay Tests: deterministic replay across versions
- Mutation Tests: safe mutation scenarios
- Branch Tests: parallel branch simulations
- Long-Session Tests: stability and resource leakage
