# Model Management

Purpose
-------
Defines how models are hosted, routed, and health-checked (local and cloud models).

Structure
---------
- Local Models: installation and lifecycle
- Cloud Models: endpoints, quotas, and failover
- Routing Policies: affinity, cost, and capability
- Model Capabilities: tags, context limits, and strengths
- Failover Policies: fallback strategies and degradation modes
- Model Health: monitoring and automated remediation
