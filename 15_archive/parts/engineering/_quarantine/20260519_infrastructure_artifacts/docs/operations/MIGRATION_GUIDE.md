# Migration Guide

Purpose
-------
Defines safe migration patterns for event schemas, memory formats, and runtime changes to preserve temporal continuity.

Structure
---------
- Schema Migrations: compatible transforms and migrations
- Event Migrations: versioned events and replay compatibility
- Memory Migrations: consolidations and backfills
- Runtime Migrations: rolling upgrade patterns
- Branch Compatibility: cross-version branch handling
