# Meta Cognition

Purpose
-------
Defines cognition about cognition: monitoring, reflection, and strategy evaluation.

Structure
---------
- Cognitive Monitoring: metrics and traces
- Strategy Evaluation: A/B and counterfactuals
- Self-Diagnostics: root-cause introspection
- Reflection: offline analysis and policy updates
- Cognitive Optimization: meta-level learning loops
