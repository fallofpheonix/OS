# Branch Cognition

Purpose
-------
Describes parallel cognitive trajectories represented as branches and how they are evaluated, merged, and pruned.

Structure
---------
- Branch Simulation: isolated simulations per branch
- Parallel Futures: comparative evaluation
- Branch Evaluation: scoring, trust, and cost
- Merge Cognition: semantic merge strategies and invariants
- Evolutionary Search: mutation and selection of strategies
