# Uncertainty Model

Purpose
-------
Defines how uncertainty is quantified, propagated, and used to gate decisions and escalations.

Structure
---------
- Confidence Representation: scales and calibration
- Uncertainty Sources: model, environment, data
- Escalation Policies: thresholds for human-in-loop
- Confidence Decay: time-based degradation
- Ambiguity Resolution: exploration vs exploitation policies
