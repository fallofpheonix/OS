# Planning System

Purpose
-------
Describes goal decomposition, simulation, branch exploration, and plan selection used by cognition.

Structure
---------
- Goal Decomposition: subgoals and success criteria
- Temporal Planning: schedules and ordering constraints
- Branch Exploration: candidate plan generation
- Simulation: forward rollout and scoring
- Constraint Satisfaction: invariants and resource checks
- Plan Revision: monitoring, replanning, and repair
