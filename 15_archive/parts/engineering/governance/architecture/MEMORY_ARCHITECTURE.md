# Memory Architecture

Defines the structure and lifecycle of the memory tiers used by the cognition substrate.

Sections
--------
- Memory tiers: Working, Episodic, Semantic, Procedural
- Storage backends and schemas
- Consolidation pipeline (dream cycles)
- Retrieval and decay policies
- Replay and verification
- Ownership and access controls

Design principles
-----------------
- Memory is part of cognition: access patterns are first-class design considerations.
- Consolidation runs during idle/dream cycles and produces semantic artifacts tied to ADRs.
