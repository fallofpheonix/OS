Overview
========

This folder contains the top-level governance documents for the engineering ecosystem.
It implements the documentation-as-infrastructure model for Astraeus and related projects.

Structure
---------
- vision/: Vision and principles
- constitution/: Invariants, constitution, safety rules
- architecture/: System and runtime architecture docs
- cognition/: Memory, world-model, and cognition design
- operations/: Setup, runtime, observability, and CI/CD
- evolution/: Roadmaps, phases, ADRs, changelogs

Status
------
This repo contains scaffolding templates created on 2026-05-15. Fill each file's TODOs to complete the docs.
