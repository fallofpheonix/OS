# RFC: Phoenix Bus

## 1. Description
The Phoenix Bus is a high-speed, in-memory message distribution system. It is designed to handle the massive event volume generated by eBPF collectors.

## 2. Specification
- **Pattern:** Publish/Subscribe.
- **Concurrency:** Thread-safe via RWMutex.
- **Safety:** Non-blocking publish with subscriber drop-protection.

## 3. Schema
All messages MUST contain:
- `topic`: Source/Category.
- `id`: Event UUID.
- `ts`: Timestamp (nanoseconds).
- `data`: Payload.
