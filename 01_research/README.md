# Research

Immutable research area.

Allowed:

- Literature notes.
- Topic maps.
- Stage prerequisites.
- Lab descriptions.
- Checkpoints.
- Research-only diagrams.
- Open questions.

Forbidden:

- Production code.
- Runtime configuration.
- Generated binaries.
- Dataset payloads.
- Secrets.
- Malware samples.

Promote research into implementation only by copying conclusions into `02_docs/` or implementation tasks into the relevant code area.
