# Phase 0 Implementation Labs

## Rule

Research stays in `01_research/`. Actual implementation code should be placed under `14_experiments/poc/stage_00_foundations/` or a dedicated implementation path when created.

## Lab 00: Number Systems And Bit Operations

Output:

- Decimal/binary/hex conversion notes.
- Bit operation examples.
- Mask/flag examples.

Gate coverage:

- Binary and hexadecimal.
- Bit operations.

## Lab 01: Memory Model

Output:

- Stack vs heap diagram.
- Pointer/reference examples.
- Alignment and padding notes.

Gate coverage:

- Memory model.
- Lifetime and scope.

## Lab 02: Sequential Data Structures

Implement:

- Dynamic array.
- Singly linked list.
- Doubly linked list.
- Stack.
- Queue.
- Circular buffer.

Required tests:

- Empty structure.
- Single element.
- Multiple elements.
- Insert/delete at head.
- Insert/delete at tail.
- Search miss.
- Search hit.

## Lab 03: Trees And Heaps

Implement:

- Binary tree traversal.
- Binary search tree insert/search.
- Min-heap.
- Max-heap.

Required tests:

- Empty tree.
- One-node tree.
- Balanced tree.
- Degenerate tree.
- Duplicate handling policy.

## Lab 04: Hash Table

Implement one collision strategy:

- Chaining, or
- Open addressing.

Required tests:

- Insert.
- Lookup.
- Delete.
- Collision.
- Resize.
- Missing key.

## Lab 05: Searching And Sorting

Implement:

- Linear search.
- Binary search.
- Insertion sort.
- Merge sort.
- Quick sort.

Required notes:

- Input preconditions.
- Stability.
- Time complexity.
- Space complexity.

## Lab 06: Graphs

Implement:

- Adjacency list graph.
- Adjacency matrix graph.
- DFS.
- BFS.
- Topological sort.
- Shortest path baseline.

Required tests:

- Disconnected graph.
- Cycle.
- DAG.
- Single node.
- No edges.

## Lab 07: Concurrency And State

Implement or model:

- Race condition demonstration.
- Critical section protected by a lock.
- Deadlock example in notes only.
- Finite-state machine.

Required notes:

- Shared state.
- Invariants.
- Transition table.
- Failure states.

## Lab 08: Problem-Solving Set

Solve 10-15 Easy problems.

For each problem record:

- Problem name.
- Data structure used.
- Brute-force complexity.
- Final complexity.
- Edge cases.
