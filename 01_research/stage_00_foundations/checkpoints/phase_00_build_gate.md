# Phase 0 Build Gate

## Rule

This gate must pass before moving into Stage 01 system internals implementation.

## Knowledge Verification

- [ ] Binary and hexadecimal: convert between decimal, binary, and hex.
- [ ] Bit operations: explain AND, OR, XOR, NOT, shifts, masks, and flags with code examples.
- [ ] Memory model: draw and explain stack vs heap.
- [ ] Lifetime and scope: explain variable lifetime, ownership, and scope.
- [ ] Big O analysis: identify time and space complexity of code.
- [ ] Complexity trade-offs: compare brute-force and optimized approaches.
- [ ] Graph basics: explain DFS vs BFS.
- [ ] Traversal use cases: identify when DFS or BFS is appropriate.

## Implementation Skills

- [ ] Singly linked list with insert, delete, and search.
- [ ] Stack using array.
- [ ] Stack using linked list.
- [ ] Queue using array or circular buffer.
- [ ] Queue using linked list.
- [ ] Binary search with sorted-input precondition documented.
- [ ] Merge sort with complexity comments.
- [ ] Quick sort with partition logic explained.
- [ ] Hash table with collision handling.
- [ ] Tree traversals:
  - [ ] In-order.
  - [ ] Pre-order.
  - [ ] Post-order.
  - [ ] Level-order.
- [ ] Graph traversal:
  - [ ] DFS from scratch.
  - [ ] BFS from scratch.

## Problem-Solving

- [ ] Solve 10-15 LeetCode Easy problems using appropriate data structures.
- [ ] Optimize at least one brute-force solution using complexity analysis.
- [ ] Design a simple finite-state machine for a real-world scenario.
- [ ] Explain when to use each fundamental data structure.

## Code Quality

- [ ] Clean, readable code.
- [ ] Meaningful variable names.
- [ ] Complexity analysis comments on implementations.
- [ ] Edge cases handled:
  - [ ] Empty structures.
  - [ ] Single element.
  - [ ] Duplicate values where relevant.
  - [ ] Out-of-range input.
  - [ ] Allocation failure where relevant.

## Pass Criteria

All required checkboxes complete, with code and notes linked from `labs/phase_00_implementation_labs.md`.
