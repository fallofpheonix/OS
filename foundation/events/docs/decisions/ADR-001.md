---\nStatus: Implemented\nImplementation: 100%\nConfidence: Proven\n---\n# ADR-001: JSON Encoding for Event Payloads

## Context
We need a serialization format that is readable by human audits but performs well enough for the event bus.

## Decision
Event payloads use `json.RawMessage` to allow lazy evaluation of nested data schemas without breaking the outer envelope structure.

## Consequences
- **Pros**: Interoperability, easy debugging.
- **Cons**: Slower than Protobuf or FlatBuffers; requires optimized JSON parsers.
