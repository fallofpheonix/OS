---\nStatus: Implemented\nImplementation: 100%\nConfidence: Proven\n---\n# ADR-001: Schema Isolation and Version Isolation

## Context
Downstream packages (e.g. `runtime`, `ledger`) need access to contracts without bringing in implementation details that cause circular imports.

## Decision
All public types are defined as interfaces in `foundation/contracts`. Concrete structs are isolated inside their respective implementing directories (e.g. `foundation/events`).

## Consequences
- **Pros**: Zero circular dependencies; clean layering.
- **Cons**: Increased interface boilerplate.
