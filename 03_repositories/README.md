# Repositories

Repository tracking and open source alignment.

## Classes

- `learn_from/`: references to study.
- `contribute_to/`: active upstream contribution targets.
- `forked/`: forks owned by the project.
- `integrated/`: third-party repositories integrated into builds.
- `archived/`: no longer active.
- `experiments/`: temporary repository trials.

Do not vendor external repositories here unless explicitly approved.
