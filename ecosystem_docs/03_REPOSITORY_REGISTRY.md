# 03 REPOSITORY REGISTRY

## Purpose
Tracking all repositories within the ecosystem.

## Fields
- **Repo**: Name of the repository.
- **Role**: Function within the ecosystem (Core, Research, Archive, etc.).
- **Status**: Active, Inactive, Archived.
- **GitHub**: Remote URL.
- **Runtime**: Integration status.
- **Priority**: High, Medium, Low.
- **Archive**: Location in archive if applicable.
