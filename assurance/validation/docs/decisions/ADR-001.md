---\nStatus: Implemented\nImplementation: 100%\nConfidence: Proven\n---\n# ADR-001: Separation of Proofs and Tests

## Context
Downstream developers need to verify their systems without pulling in heavy security exploit simulator payloads.

## Decision
Proofs (causal, FSM, ordering) are separated into the `proofs/` subpackage. Malicious exploit payload simulations reside in `security/` and are built conditionally using Go build tags.

## Consequences
- **Pros**: Cleaner production test dependencies.
- **Cons**: Requires managing custom build tags (`//go:build exploits`).
