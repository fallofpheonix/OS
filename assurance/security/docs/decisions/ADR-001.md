---\nStatus: Implemented\nImplementation: 100%\nConfidence: Proven\n---\n# ADR-001: Containment Ladder State Model

## Context
Securing process domains needs a granular scaling mechanism. Binary (safe/unsafe) security models are too rigid.

## Decision
We enforce a 5-step containment ladder (`LevelNone`, `LevelMonitor`, `LevelSandbox`, `LevelIsolate`, `LevelQuench`) allowing localized process isolation before terminating whole namespaces.

## Consequences
- **Pros**: Reduces system downtime; gradual mitigation.
- **Cons**: Complexity in debugging multi-layer actuator escalations.
