---\nStatus: Draft\nImplementation: 0%\nConfidence: High\n---\n# Extraction Rules\n\n> This document defines the requirements for making subprojects "extraction-ready".\n\n## 1. Independence Requirements\n\n- **Zero Cross-Module Imports:** A module cannot import from a sibling module. It must go through a shared `contract` in the Foundation layer.\n- **Self-Contained Configuration:** Modules must manage their own configuration and state without relying on global monorepo variables.\n- **Interface-First:** Every public feature must have a corresponding interface in `foundation/contracts`.\n\n## 2. Extraction Readiness Check\n\n- All extraction-ready modules must maintain a `docs/EXTRACTION_READINESS.md` file tracking their progress.\n\n--- \n*Refer to [docs/extraction/EXTRACTION_ORDER.md](../extraction/EXTRACTION_ORDER.md) for the roadmap.* \n
