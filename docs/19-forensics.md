# Digital Forensics

## Modules

### Memory

- Dump capture.
- RAM analysis.
- Volatility support.
- Process extraction.
- Kernel object inspection.

### Disk

- Image acquisition.
- File recovery.
- Timeline reconstruction.
- Hash inventory.
- Deleted-file analysis.

### Network

- Packet capture.
- Session rebuild.
- DNS history.
- TLS metadata.
- Flow reconstruction.

## Artifact Sources

- Browser artifacts.
- Registry-like configuration stores where applicable.
- Logs.
- Kernel traces.
- Containers.
- Package manager history.
- Authentication records.

## Tooling

- Volatility.
- Autopsy.
- Sleuth Kit.
- Zeek.
- Wireshark or tshark.

## Evidence Requirements

- Preserve original artifact.
- Hash before analysis.
- Record acquisition time.
- Record analyst and tool version.
- Maintain chain of custody.
- Separate working copy from evidence copy.
