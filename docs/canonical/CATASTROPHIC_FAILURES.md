---\nStatus: Draft\nImplementation: 0%\nConfidence: High\n---\n# Catastrophic Failures\n\n> This document defines S1-level failures that threaten system integrity and the "Fail-Closed" protocol.\n\n## 1. S1 Failure Definitions\n\n- **Invariant Violation:** Any breach of `docs/MASTER_INVARIANTS.md`.\n- **Ledger Divergence:** Two nodes disagreeing on the canonical event history.\n- **Authority Escalation:** A module exercising authority it was not delegated.\n\n## 2. Fail-Closed Protocol\n\n1. **Lock Actuators:** All physical and system actuators are moved to a safe state and locked.\n2. **Isolate Cognition:** AI agents are suspended and their capabilities revoked.\n3. **Halt Mutability:** The Ledger enters read-only mode.\n4. **Emit Beacon:** An emergency diagnostic beacon is emitted to all available listeners.\n\n--- \n*Refer to [FAILURE_CATALOG.md](./FAILURE_CATALOG.md) for the full error list.* \n
