# GitHub Repos And Open-Source Resources

Essential repositories and projects for security operations with ML support.

## 1. Complete Platforms

### Security Onion

- Repository: `security-onion-solutions/security-onion`.
- Purpose: IDS/IPS platform using tools such as Zeek, Suricata, Elasticsearch, and Kibana.
- Use: integrated network security monitoring.

### Wazuh

- Repository: `wazuh/wazuh`.
- Purpose: open-source EDR/SIEM.
- Use: endpoint agents, log collection, detection rules, compliance.

## 2. Network Monitoring

### Zeek

- Repository: `zeek/zeek`.
- Purpose: network analysis framework.
- Output: structured logs suitable for Elasticsearch and SIEM pipelines.

### Suricata

- Repository: `OISF/suricata`.
- Purpose: multi-threaded IDS/IPS.
- Use: signature detection, protocol analysis, threat-feed integration.

## 3. ML And Anomaly Detection

### ML-KDD

- Repository: `iosig/ML-KDD`.
- Purpose: ML models for KDD99 intrusion-detection data.

### IDS-ML

- Repository: `Mknight-03/IDS-ML`.
- Purpose: intrusion detection using machine learning.
- Models: XGBoost, Random Forest.

### NuPIC

- Repository: `numenta/nupic`.
- Purpose: hierarchical temporal memory and unsupervised anomaly detection.

## 4. Incident Response And SOAR

### Shuffle

- Repository: `frikky/shuffle`.
- Purpose: SOAR platform.
- Use: security workflows, tool orchestration, automation.

### n8n

- Repository: `n8n-io/n8n`.
- Purpose: workflow automation.
- Use: webhook/API-driven response flows.

### TheHive

- Repository: `TheHive-Project/TheHive`.
- Purpose: case management and incident response.
- Integration: Cortex analyzers.

## 5. Threat Intelligence

### MISP

- Repository: `MISP/MISP`.
- Purpose: threat intelligence and IOC sharing.

### OpenCTI

- Repository: `OpenCTI-Platform/opencti`.
- Purpose: graph-based threat intelligence.

## 6. Log Analysis And SIEM

### Elasticsearch

- Repository: `elastic/elasticsearch`.
- Purpose: search and analytics engine for log aggregation.

### Graylog

- Repository: `Graylog2/graylog2-server`.
- Purpose: log aggregation and analysis.

## 7. Vulnerability And Malware Analysis

### OWASP ZAP

- Repository: `zaproxy/zaproxy`.
- Purpose: dynamic application security testing.

### Cuckoo Sandbox

- Repository: `cuckoosandbox/cuckoo`.
- Purpose: automated malware analysis.
