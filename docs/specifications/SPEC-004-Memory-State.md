---\nStatus: Draft\nImplementation: 0%\nConfidence: High\n---\n# SPEC-004: Memory State & Truth Model\n\n> This specification defines the format for long-term "proven" facts and beliefs within the Cognition layer.\n\n## 1. Truth Model Structure\n\nThe Truth Model is a Merkle DAG of `Fact` objects.\n\n```text\nFact {\n    FactID: UUID\n    Claim: Statement (Predicate-Subject-Object)\n    EvidenceLinks: List<EventID> (Provenance)\n    Confidence: ConfidenceScore (SPEC-Confidence-Math)\n    Timestamp: uint64 (Last Verified Tick)\n}\n```\n\n## 2. Belief Revision Rules\n\n- **Contradiction Handling**: If a new `Event` contradicts an existing `Fact`, the `Fact`'s confidence is decayed. If confidence falls below the $T_{doubt}$ threshold, the `Fact` is moved to "Hypothesis" status.\n- **Provenance Requirement**: No `Fact` can exist without at least one `EvidenceLink` to a finalized Ledger block.\n\n## 3. Tiered Storage\n\n- **HOT (Reasoning Buffer)**: Currently active facts in high-speed RAM.\n- **WARM (Truth Model)**: Full set of verified facts, indexed for graph queries.\n- **COLD (Ledger)**: Raw evidence events, archived and compressed.\n\n--- \n*Refer to [docs/phoenixmind/theory/MEMORY_SCORING.md](../phoenixmind/theory/MEMORY_SCORING.md) for eviction rules.* \n
