---\nStatus: Draft\nImplementation: 0%\nConfidence: High\n---\n# Memory Scoring & Prioritization\n\n> This document defines how PhoenixMind scores and manages the lifecycle of memories.\n\n## 1. Scoring Factors\n- **Recency:** Time since last access.\n- **Frequency:** Number of times accessed.\n- **Utility:** Correlation with high-reward outcomes.\n- **Certainty:** Confidence score at time of recording.\n\n## 2. Eviction Policy\n- Memories with scores below $T_{evict}$ are archived to long-term storage (Ledger) and removed from volatile reasoning buffers.\n\n--- \n*Refer to [docs/phoenixmind/MEMORY_MODEL.md](../MEMORY_MODEL.md) for architectural details.* \n
