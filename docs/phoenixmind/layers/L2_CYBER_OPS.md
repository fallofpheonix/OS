# L2 Cyber Operations — Capability Spec

L2 monitors system security health, scans processes for malicious behaviors, and isolates compromised nodes.

## Main Algorithms
- **Signature matching**: Standardized heuristics for detecting known threat payloads.
- **Dynamic containment escalation**: Invokes process isolation namespaces when threshold metrics drop.
